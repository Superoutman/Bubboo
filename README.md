# Bubboo

English | [简体中文](README.zh-CN.md)

Bubboo brings instant actions to selected text on your Mac. A lightweight floating toolbar appears beside your selection.

## Features

- Copy, paste, and search the web.
- Import `.popclipext` / `.popclipextz` extensions, with support for selected URL, Shell, AppleScript, and JavaScript actions.
- Customize the toolbar and manage extensions in native macOS settings.
- Opening Settings checks for curated extension updates, with a six-hour cache. Upgrade individual packages manually while keeping their settings. Changed content requires fresh approval; extensions are never upgraded automatically.
- Built-in actions show a lock instead of a delete button. The Dock icon appears while Settings is open.
- Remove installed extensions to the Trash, or open the curated download collection from Settings.
- English and Simplified Chinese follow your system’s preferred language. Other languages fall back to English.


## Downloads and updates

**Requires macOS 14.0 (Sonoma) or later.**

**Current version: 0.1.4 · Apple Silicon (M-series chips).**

The app is signed with Developer ID and notarized by Apple. An Intel build is not currently available.

This repository is the official source for product information, downloads, and updates. Installers are available in Releases. Click the version number in Settings to check for updates; a green prompt appears when an update is available. Automatic checks and downloads can be managed in About. The app uses this repository’s appcast for updates.

## Getting started

Extract the download, move `Bubboo.app` to Applications, and open it. Allow Bubboo in **System Settings → Privacy & Security → Accessibility**, then select text to use the toolbar.

New or modified extensions are disabled until you explicitly enable them. Script extensions can perform local operations, so only enable extensions you trust. JavaScript network access requires approval for each domain.

## Extensions

Bubboo extensions give you more ways to work with selected text: search different services, translate, reformat text, or connect a task to a tool you already use. Choose the actions that suit your workflow and keep your toolbar focused on what you need.

This collection makes extensions easier to discover, compare and install. It brings downloads, minimum App versions, original authors and adaptation notes into one place, reducing the effort of finding packages and checking whether they work. The aim is to offer more useful choices while preserving the original creators' work and making sources and changes easy to inspect.

**31 tested extensions are available below.** Packages are included after compatibility review and real-use testing in Bubboo; this is a curated starting point, not a complete catalog of PopClip extensions. Some packages need adaptations. Open an extension's name to review its source, changes and tested limitations before installing.

**Install and update:** Download a `.popclipextz` package below, import it in Settings and enable it. Configure available options there. Bubboo 0.1.4 checks for extension updates when Settings opens, with a six-hour cache. Upgrade manually; your settings are retained and changed content requires renewed approval. Extension versions are independent of App versions; check the minimum App version in the table.

**Compatibility:** Testing does not cover every OS, regional site or third-party service. Required apps must be installed, and websites may require sign-in or restrict availability. Web searches send selected text to the destination site; scripts can perform local operations. Enable extensions you trust. See the [extension guide](https://github.com/Superoutman/Bubboo-Extensions#current-stable-collection) for details.
